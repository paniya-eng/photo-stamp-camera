# Photo Stamp Camera

اپلیکیشن دوربین با قابلیت درج تاریخ و ساعت روی عکس + تنظیمات کامل.

## ویژگی‌ها (MVP)

- پیش‌نمایش زنده دوربین
- گرفتن عکس
- درج تاریخ و ساعت روی تصویر (با کیفیت اصلی)
- تنظیمات قابل ذخیره:
  - موقعیت مهر (بالا چپ، بالا راست، پایین چپ، پایین راست، وسط)
  - اندازه فونت
  - رنگ متن
  - شفافیت
  - فرمت تاریخ
  - پس‌زمینه متن
- ذخیره مستقیم در گالری گوشی

## ساخت APK

```bash
flutter pub get
flutter build apk --release
```

فایل APK در مسیر زیر ساخته می‌شود:

`build/app/outputs/flutter-apk/app-release.apk`

## اجرا روی دستگاه

```bash
flutter run
```

## پلتفرم‌ها

- Android (اولویت)
- iOS (آماده برای توسعه بعدی)

## مجوزها

- CAMERA
- READ/WRITE STORAGE (برای نسخه‌های قدیمی‌تر اندروید)
- READ_MEDIA_IMAGES

ساخته شده با Flutter.
